# Security

Do not include Latvijas Pasts API credentials, OpenCart configuration files,
database exports or production logs in issues or pull requests.

The generated package contains no store-specific configuration. Configure the
extension only in the OpenCart administrator after installation, and keep all
shipping components disabled until credentials and tariffs have been tested.

For a security issue in this compatibility builder, open a GitHub security
advisory instead of a public issue. Issues in the upstream shipping API or
business service should be reported to Latvijas Pasts.
